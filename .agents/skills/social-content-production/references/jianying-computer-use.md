# 剪映专业版：Computer Use 执行参考

适用：用户指定剪映桌面版进行本地制作或修改。优先验证 Windows；macOS、移动版和 CapCut 是不同环境，不能继承按钮、快捷键、项目格式或能力结论。本参考是操作方法，不是已完成的实机验证。

## 进入软件前

1. 固定脚本、主平台、当前包版本和实际素材台账。只为当前任务打开必要工程；不为“设置技能”新建真实业务工程。
2. 读取当前环境的 Computer Use 技能及其 guidance、API、confirmations；以当前可用版本为准，不把维护者的插件路径写进共享方法。仓库不提供运行器或授权。
3. 先执行轻量只读连接检查，再列应用/窗口。若当前插件使用 Windows `node_repl + @oai/sky`，初始化及列表的形状如下；执行前仍核对当前插件说明：

```js
if (!globalThis.sky) {
  const { sky } = await import("@oai/sky");
  globalThis.sky = sky;
}
globalThis.apps = await sky.list_apps();
nodeRepl.write(JSON.stringify(apps.filter(app =>
  /剪映|jianying/i.test((app.displayName || "") + " " + app.id)
), null, 2));
```

这只是发现入口，不意味着已打开、观看或剪辑。只选实际返回的剪映应用及唯一目标窗口；没有窗口时按插件支持的方式启动已安装软件再重新选择。多个工程窗口不猜当前对象。记录系统、软件显示版本、语言、缩放及项目帧率的可见依据，未知留空。

Windows 桌面保持可操作且不要同时手动操作；锁屏就停。运行器在 JS 初始化前报环境/路径错误时记录失败阶段，不能靠换坐标、Shell UI 自动化或改权限绕过。超时与恢复按当前插件规则有限重试；错误持续则继续方案和文字，不把连接失败称已验证剪映。

## 小样与能力记录

真实制作前，使用用户当前提供的少量素材，验证一次短小样：导入 → 加入时间线 → 非破坏修剪/分割 → 一处文本或字幕 → 保存可恢复工程 → 本地导出 → 打开导出文件检查。没有素材时不凭空生成“已通过”的小样。

逐项保留 `tested / not_tested / failed`、输入摘要、实际操作、证据、输出和范围。连接、截图、能点击、识别字幕、导出、动态观看和听校分别记录；前一项成功不代表后一项成功。软件更新、换系统、工程或媒体格式后只重测受影响项，生成新 `capability-check-vNNN.json`，不覆盖旧包引用。

项目自身目录可能由剪映管理。先在软件中确认能否复制/另存为独立草稿；未验证功能不假定存在。保存新草稿/工程版本并记录实际位置或软件内可恢复定位；不要直接修改未验证的内部草稿JSON、移动原片或覆盖已有工程。独立副本不能确认时，先保存方案并说明工程保护缺口。

## 每次动作的循环

观察并检查当前截图/可访问树 → 选一个动作 → 执行动作 → 立即刷新确认结果。输入框先检查焦点再输入；菜单、弹窗、滚动或缩放后重新取状态。坐标、截图ID、元素索引和窗口对象仅用于当次有效观察，不写进长期参考或反馈档案。

时间轴缺少可访问树时用当前截图定位。拖拽前后核对选中片段、播放头、轨道和时间显示；不要按像素估算时间码。需要精确位置时优先当前版本可见的时间输入/步进控件，或经验证的快捷键。只读定位和播放不等于素材内容全程已检查。

| 操作 | 可执行路径与检查点 |
| --- | --- |
| 导入 | 从观察到的导入控件选择已核实的 Windows 可访问路径；核对文件名、时长及缩略图，不把搜索结果当本地素材 |
| 排序与修剪 | 以脚本镜头ID和稳定片段ID对照时间线；确认主轨/叠层/连接音轨和吸附状态，操作后检查后续片段是否意外位移 |
| 分割、变速或转场 | 核对作用对象、实际新时长和声音关系；变速/转场重算成片映射，不以源时间等同成片时间 |
| 文本/字幕 | 区分叙事文字与实录字幕；已有对齐字幕优先尝试导入，界面未提供则保留SRT和人工执行说明 |
| 识别字幕 | 先核实当前版本入口、语言、费用和是否上传/云处理；涉及新数据传输按具体素材和目的地授权，不从普通剪辑推断允许上传 |
| 字幕修改 | 先验证一条文本、时间和样式，再扩大范围；核对“应用全部”作用域，避免覆盖不同语言/说话人的例外 |
| 声音 | 在真实监听范围内处理人声、音乐和淡入淡出；未实测不写响度数值或“全片无爆音” |
| 平台版本 | 从已保护母版产生明确独立版本；分别核对画幅、主体裁切、字幕与封面，不只改文件名 |
| 工程保存 | 记录实际草稿/工程定位、媒体依赖、版本和最后已验证状态；只看到自动保存提示不等于已经验证重开恢复 |
| 本地导出 | 区分本地导出与发布/分享/云同步；确认输出新路径、范围、字幕烧录、尺寸/帧率/编码及无覆盖提示 |

同一动作失败最多在重新观察后再试一次；若可能已执行，先核对结果，不盲目再次导入、粘贴、分割或导出。模态框可能是另一个窗口，应重新列出并绑定当前目标。用户中断则停止输入，下次恢复重新观察。

权限与确认以当前 Computer Use 技能为准。通过界面删除片段、字幕、草稿或文件等若属于其删除数据规则，就在该动作前说明具体对象并按规则确认；普通观察不需另加批准。认证、安全/隐私设置与密码窗口交给用户，不能自动处理。会员功能、付费素材、云上传和账号发布不在普通本地剪辑范围内。

## 时间、字幕与导出

源片时间、脚本计划时间、工程显示时间及导出时间分开。时间码采用 `HH:MM:SS:FF` 时必须知道准确帧率、时间基及是否drop-frame，不能把最后两位直接当毫秒。工程显示与实际导出偏移核对后才转换为剪辑表/SRT秒数。稳定片段ID贯穿版本，删前段或变速后保存映射。

自动字幕是待校对转写；按实际录音核对人名、数字、否定词和断句，听不清保留待确认。如果用户只提供脚本而未听音频，不把脚本当ASR结果。外部SRT与烧录字幕分别保留，检查导出是否出现双层字幕；平台自动字幕尚未确定时列发布前待办。

导出前查拟交付平台当前必要规格，记录来源和核查日期；不将固定分辨率/码率当长期平台规则。导出进度100%仅表示渲染步骤结束，还需核对：

- 实际文件存在且非空、摘要、时长、尺寸、方向与计划；
- 成片开头、切点、字幕及结尾的动态检查范围；抽帧不能替代播放；
- 实际听校范围和字幕同步；没有音频通道就保留未验证；
- 有无黑帧、截断、离线素材、默认片尾、非预期水印、重复字幕及文案不一致。

只有符合当前交付要求的真实文件才标可交粗剪/待审核；工程、导出弹窗、缩略图不算成片。未知或会员水印问题保留缺口，不购买或绕过限制。发布批准固定到账号、平台、整包摘要和必要设置，任何项变化产生新版待审核。

## 断点、反馈与可复用经验

在当前制作包记录 `editor-session-vNNN.json` 或同义条目：工具/版本、工程定位、脚本与包摘要、最后成功动作、当前选择/时间线的文字描述、实际导出、已知失败、下一步和未验证项。截图证据按当前工具允许方式引用，不保存截图payload或把截图ID当跨会话句柄。个人路径与窗口内容只留被忽略的运行目录。

反馈固定到预览摘要、片段ID及导出时间段；旧版反馈先映射后修改。每轮新工程/包记录输入、变更和字幕/声音/封面的影响；只改文字也升整包版本，可复用原视频摘要。与第四步对接见 [留存到剪辑](../../social-performance-review/references/retention-to-edit.md)。

实测后只提炼稳定入口、前后检查条件和适用软件版本；一次成功不宣布所有电脑可用，不把偶发按钮位置写成永久方法。共享的是方法，运行器错误、用户窗口、素材、真实检查点和成片不会随仓库分发。
