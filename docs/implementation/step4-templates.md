## 6. 可复用提示

**整理数据**

> 将这些发布登记、截图和表格整理为可追溯的表现快照。保留原名、单位、分母、实际数据年龄及时间范围；模糊或缺失值别当零，不从晚到的累计数倒推D1。先说明本轮能分析什么。

**复盘**

> 基于指定D1/D7快照、实际发布版本与发布前目标复盘。比较可比历史，列出事实、原因假设和未知，更新D1判断。优先提出一个实验，并给下一条选题方向和具体开场或镜头改法；不宣称单条结果证明因果。

**反馈到创作**

> 在第二步使用指定版本的创作简报、当前研究和已确认画像提出选题，说明每条学习记录采用或暂缓的理由。我选方向后再写完整脚本；不要自动改掉已有定稿或长期画像。


## 修订、互补与定位的最小示例

以下只是字段约定，不是真实记录，也不自动创建内容档案。旧字段按原义读取，缺稳定关系或来源时标待核实，不凭数组位置回填。

```json
{
  "row_id": "example-row-v002",
  "publication_id": "example-publication",
  "snapshot_key": "example-observation",
  "version": 2,
  "supersedes": "example-row-v001",
  "complements": null,
  "data_through": null,
  "source": {"path": null, "sha256": null, "json_pointer": "/raw_observations/1"},
  "values": {"Views": null, "Saves": null}
}
```

修订用supersedes指向稳定旧ID；互补记录使用另一row_id、complements指向同帖同截止的目标，重叠指标只核对不累加，冲突则待核实/拒绝。来源Pointer与输入SHA一起固定，重排时重新定位，不能沿用旧数组索引。此约定补充来源关系，不更改第二步的learning/brief版本与摘要接口，也不强制迁移历史档案。
